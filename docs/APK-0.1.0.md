Lataa **Uutishetki-0.1.0.apk** alla olevista tiedostoista ja avaa se Android-puhelimessa. Salli tarvittaessa selaimelle tai tiedostonhallinnalle sovellusten asentaminen. Android 8.0 tai uudempi.

Mukana viisi uutislähdettä, lähde- ja aihesuodattimet, offline-otsikot ja -kuvaukset, kuvat sekä artikkelien avaaminen selaimeen. Ei omia mainoksia tai käyttäjätilejä.

Tämä on testiallekirjoitettu debug-APK, jonka voi asentaa tavallisesti ilman avainten tai GitHub Secrets -asetusten määrittämistä. Se on Actions-ajon 41980473924 tarkistettu paketti. Pysyvää julkaisuavainta ei ole otettu käyttöön, joten tuleva versio voi vaatia vanhan sovelluksen poistamisen ennen asentamista; silloin paikalliset uutiset poistuvat.

Tarkistukset: kahdeksan yksikkötestiä, Android Lint ja APK-käännös läpäisty. Ei laitetestiä. Ylen alueuutisissa ei havaittu kuvia, Yle Häme tarkoittaa Kanta-Hämettä ja aiheluokittelu on rajallinen. Sanoman RSS-erityisehtoja ei voitu varmistaa; sovellus on tarkoitettu yksityiseen lukemiseen.
